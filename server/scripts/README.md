# Сервисные утилиты сервера

Эти скрипты не нужны для обычного запуска через Docker.
Путь от корня проекта: `server/scripts/`. Клиентские команды разработки
и сборки находятся отдельно, в `client/package.json`.

| Скрипт | Назначение |
|---|---|
| `backup_data.py` | Резервное копирование и восстановление данных |
| `database_admin.py` | Миграция JSON → SQLite, проверка, количество записей и снимок БД |
| `oauth_status_check.py` | Диагностика локальных OAuth-токенов |
| `rotate_oauth_tokens.py` | Ручное обновление токенов; бот также обновляет их самостоятельно |
| `mobile_smoke_test.py` | Проверка HH API реальными GET-запросами |
| `migrate_sessions_dedup_by_user.py` | Миграция дубликатов сессий; используется тестами |

Все инструменты состояния читают SQLite, не старые JSON. `database_admin.py
backup --output ...` делает согласованный снимок. Команды `migrate` и `verify`
проверяют исходные JSON и требуют остановленного сервера. Остальные команды
этой утилиты (`status`, `backup`) допустимы при работающем боте.

Перед использованием читайте `--help`. Операции backup/restore, ротации
и миграции по умолчанию работают в dry-run; запись требует `--apply`.
Не применяйте миграцию или восстановление к данным работающего бота.
Не публикуйте диагностические отчёты без проверки персональных данных.
